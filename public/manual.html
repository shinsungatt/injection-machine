1 시스템 개요

사출설비 선택 시스템은 고객사로부터 받은 파트리스트(BOM)를 업로드하면 각 파트에 적합한 사출성형 설비(호기)를 자동으로 추천해 주는 웹 기반 업무 지원 도구입니다.

주요 기능
  • Excel BOM 파일 자동 파싱 — 한글·영문·혼용 컬럼명 모두 인식
  • 투영면적·금형 크기 자동 계산 (제품 사이즈 입력 시)
  • 형체력·사출량·금형 크기 기반 적합 설비 자동 추천
  • 설비 활용률 (60~85% 권장) 기준 최적 순위 제공
  • 예상 사이클타임(C/T) 자동 예측
  • PDF 도면 AI 자동 분석 (도번·품명·재질·치수 추출) NEW
  • 도면 PDF / CAD / STP 대용량 파일 첨부 (제한 없음) NEW
  • 고객사별 프로젝트 이력 통합 조회 NEW
⚠️ 사용 환경
인터넷 브라우저 (Chrome 권장)에서 접속합니다. 별도 설치 불필요.
서비스 주소: https://injection-machine.vercel.app

⚠️ 설비를 삭제하면 해당 설비로 생성된 추천 결과도 함께 삭제됩니다.

4 프로젝트 생성 및 관리

고객사 프로젝트(견적 건)별로 관리합니다.

새 프로젝트 만들기

  1. 상단 프로젝트 메뉴 클릭

6 파트 수동 입력

Excel 없이 파트를 직접 입력할 수 있습니다.

  1. 프로젝트 상세 화면에서 + 파트 수동 입력 버튼 클릭
  2. 파트번호, 파트명, 재질 선택
  3. 제품 사이즈(mm) 입력 → 투영면적·금형 크기 자동 계산
  4. 중량(g), 캐비티 수 입력 후 저장

7 설비 추천 실행

  1. 파트리스트 업로드 또는 수동 입력 완료
  2. 프로젝트 상세 화면 오른쪽 상단 설비 추천 실행 버튼 클릭
  3. 분석이 완료되면 결과 보기 버튼 활성화
추천 기준
  • 필요 형체력 ≤ 설비 형체력
  • 필요 사출량 ≤ 설비 최대 사출량
  • 금형 크기 ≤ 설비 타이바/플래튼 크기
  • 형체력 활용률 60~85% 범위를 최우선 추천
  • 70%에 가장 가까운 설비를 1위로 선정
⚠️ 투영면적이 0이면 형체력 계산을 건너뜁니다. 중량이 0이면 사출량 계산을 건너뜁니다.

9 도면·CAD·STP 파일 관리 & AI 분석

프로젝트 상세 화면의 파일 업로드 카드에서 첨부 파일을 관리합니다.

파일 업로드

카드허용 형식최대 크기업로드 방식
파트리스트 Excel .xlsx, .xls, .csv 제한 없음 서버 파싱 후 DB 저장
도면 PDF .pdf 제한 없음 NEW Supabase Storage 직접 업로드
도면 CAD .dwg, .dxf, .sldprt, .prt 제한 없음 NEW Supabase Storage 직접 업로드
STP 파일 .stp, .step, .igs, .iges 제한 없음 NEW Supabase Storage 직접 업로드
✅ PDF·CAD·STP 파일은 브라우저에서 Supabase Storage에 직접 업로드되므로 서버 용량 제한 없이 대용량 도면도 올릴 수 있습니다. 업로드 진행률이 실시간으로 표시됩니다.

AI 도면 분석 (PDF 전용) NEW

업로드된 PDF 도면에서 파트 정보를 AI가 자동으로 추출합니다.

✨ AI 분석 추출 항목
  • 도번 (part_number) — 도면 표제란 도번
  • 품명 (part_name) — 도면 품명
  • 재질 (material) — ABS, PC+ABS, PP-GF30 등
  • 제품 치수 — 가로·세로·높이(mm)
  • 투영면적(cm²) — 치수에서 자동 계산
  • 중량(g) — 도면 기재 중량
  • 캐비티 수 — 도면 기재 수량
  • 특이사항 — 슬라이드·언더컷·표면처리 등

AI 분석 사용 방법

  1. PDF 도면 파일 업로드 완료 후 목록에서 해당 파일 확인
  2. 파일 옆 ✨ AI분석 버튼 클릭
  3. 분석 완료 후 추출된 파트 정보 확인 (보라색 카드로 표시)
  4. 파트 추가 버튼 클릭하면 파트리스트에 바로 등록
⚠️ AI 분석은 Claude AI API를 사용합니다. 분석 비용이 발생할 수 있으며, 도면 품질과 기재 내용에 따라 추출 정확도가 달라질 수 있습니다. 추출된 데이터는 반드시 확인 후 사용하세요.

10 고객사 이력 조회 NEW

상단 메뉴 고객사 이력 을 클릭하면 고객사별로 프로젝트를 그룹핑하여 조회합니다.

주요 기능
  • 고객사명(프로젝트명) 기준으로 자동 그룹핑
  • 고객사별 모델 수, 전체 파트 수, 상태별 건수 요약
  • 카드 클릭 시 해당 고객사의 모든 모델(프로젝트) 펼쳐 보기
  • 모델별 상태, 파트 수, 등록일 표시
  • 모델명 클릭 → 해당 프로젝트 상세 화면으로 바로 이동
💡 고객사명 활용 팁: 프로젝트 생성 시 프로젝트명에 고객사 정식 명칭을 동일하게 입력하면 고객사 이력 화면에서 자동으로 묶여 표시됩니다.

12 자주 묻는 질문 (FAQ)

Q. Excel 업로드 시 "유효한 파트 데이터를 찾을 수 없습니다" 오류가 납니다.

원인: 헤더 행에 인식 가능한 컬럼명이 하나도 없거나, 헤더가 10행 이후에 위치한 경우입니다.

해결: 5장의 인식 가능한 컬럼명 목록을 참고하여 헤더 행에 품명, 재질, 중량 등 하나 이상의 컬럼명이 있는지 확인하세요. 헤더가 1~10행 안에 있는지도 확인하세요.

Q. 파트번호가 원하는 순서대로 나오지 않습니다.

파트번호가 비어 있으면 파트리스트 행 순서대로 1, 2, 3… 자동 부여됩니다. Excel에 파트번호 컬럼이 있고 값이 입력된 경우 해당 값이 그대로 사용됩니다.

Q. 구분(mold_type) 컬럼이 있는데 일부 파트가 누락됩니다.

구분 컬럼에서 PRESS·DIE·CAST·구매·BUY·ASSY 등 명확히 비-사출인 값만 제외됩니다. MOLD, MTC 전용 등 기타 값은 모두 포함됩니다. 제외된 행이 사출 파트라면 해당 셀 값을 MOLD로 수정하세요.

Q. 파트리스트에 부품번호(도번) 컬럼이 없어도 됩니까?

네. 파트명(품명 등)만 있어도 업로드됩니다. 파트번호가 없으면 파트리스트 순서대로 1, 2, 3… 으로 자동 부여됩니다.

Q. 설비 추천이 "추천 설비 없음"으로 나옵니다.

아래 항목을 확인하세요:

  • 투영면적(cm²) 값이 입력되어 있는지 — 0이면 형체력 계산 불가
  • 설비 관리에서 활성화된 설비가 있는지
  • 파트의 금형 크기가 모든 설비의 타이바/플래튼보다 크지 않은지

Q. 사이클타임(C/T) 값을 직접 설정하고 싶습니다.

Excel 파트리스트에 C/T, 예상 C/Time, 사이클타임 등의 컬럼을 추가하고 초(sec) 단위로 입력하면 해당 값이 우선 적용됩니다.

Q. AI 도면 분석 결과가 부정확합니다.

AI 분석 정확도는 도면 품질과 기재 내용에 따라 다릅니다. 스캔 품질이 낮거나 표제란 정보가 불명확한 경우 누락될 수 있습니다. 추출된 데이터를 화면에서 확인한 후 수정하여 등록하세요.

Q. PDF·CAD 파일은 몇 개까지 첨부 가능합니까?

파일 수·용량 제한 없이 첨부 가능합니다. 대용량 파일은 Supabase Storage에 직접 업로드되어 진행률이 실시간으로 표시됩니다.

Q. 같은 파일을 두 번 업로드하면 어떻게 됩니까?

파트가 중복 추가됩니다. 기존 파트는 삭제 후 재업로드하거나, 프로젝트 상세 화면에서 파트 목록의 🗑️ 버튼으로 개별 삭제하세요.
